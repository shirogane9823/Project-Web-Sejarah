# AGENTS.md

## Project Overview
- **Project:** Website Sejarah Bangunan Bersejarah - halaman wisata edukasi tentang Candi Borobudur.
- **Target user:** siswa, guru, dan pengunjung yang ingin mempelajari bangunan bersejarah Indonesia.
- **My skill level:** beginner-friendly.
- **Stack:** HTML, CSS, JavaScript.

## Commands
- **Install:** not required.
- **Dev:** open `index.html` in a browser, or use a static local server.
- **Build:** not required.
- **Test:** manually verify `index.html` in desktop and mobile viewport sizes.
- **Lint:** not configured.

## Do
- Read existing code before modifying anything.
- Match the simple static-site structure already used in the project.
- Keep text visible on the website in Indonesian unless the user asks otherwise.
- Keep changes small and scoped to what was asked.
- Use local assets from `assets/` when possible.
- Keep the Google Maps or Street View area easy to replace with a real iframe embed.

## Don't
- Install new dependencies without asking.
- Delete or overwrite user-provided assets without confirming.
- Hardcode secrets, API keys, or credentials.
- Add frameworks or build tools unless explicitly requested.
- Push, deploy, or force-push without permission.

## When Stuck
- If a task is large, break it into clear steps.
- If an error cannot be fixed after 2 attempts, explain the issue and the likely next step.

## Testing
- Open `index.html` after changes and verify the layout visually.
- Check both desktop and mobile widths.
- Confirm navigation links scroll to the expected sections.
- Confirm images from `assets/` load correctly.

## Git
- Keep commits small and focused if commits are requested.
- Never force push.

## Response Style
- Always respond with clear and concise messages.
- Use plain English when explaining changes to the user.
- Avoid long sentences, complex words, or long paragraphs.
